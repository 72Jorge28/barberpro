# Quickstart — BarberPro (5 minutes)

BarberPro is a **premium Next.js template** designed to be customized from **3 files**:
- `src/config/site.ts` (brand + business + navigation + links)
- `src/config/theme.ts` (theme tokens + presets + fonts)
- `src/messages/es.json` and `src/messages/en.json` (all text content)

The site supports **multi-language routing**:
- Spanish: `/es`
- English: `/en`
